# Changelog

## 0.2.0
- The character script: one composition per square character, composed from a modulated brush stroke set; class colours; ink rendering with pressure, blending and grain; a 50 % legibility floor for components.
- Animation: characters written stroke by stroke to GIF/MP4; a title sequence (`alp animate`).
- Inventory v2 (relational, deictic, logical, affect classes; six more roles; literal markers).
- Literals bound as data at ASSERT (numbers, names, times, units, references), drawn as their own characters.
- Compositional translator (clauses, roles, relative clauses, passives, coordination, anaphora) and a realizer back to English.
- `Peer` runtime: buffering/EXPAND/GROUND, challenges, checkpoint verification, rate limits, model substitution.
- SVG backend; transcripts; curated examples; CI.

## 0.1.0
- ALP/B codec, ALP/T text form, streams, RFC Appendix E translator, block renderer.
